# CookBook – Recipe Management Web App

**CookBook** is a full-stack recipe management platform built using FastAPI and vanilla front-end tech. It allows users to browse, search, and filter recipes based on ingredients, dietary needs, and available cooking devices.


## Features

- Dynamic recipe filtering by ingredients, devices, time, and dietary tags  
- Add and update recipes through custom API endpoints  
- Backend built with FastAPI, using async routes for performance  
- Debug panel to test database queries and inspect API calls  
- Responsive UI built with HTML, CSS, and vanilla JavaScript  
- Data stored in MySQL with normalized relational structure


## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (FastAPI)  
- **Database:** MySQL  
- **Tools:** Jinja2 (for templating), SQLAlchemy or databases (for ORM or raw queries), Uvicorn (ASGI server)
